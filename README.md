# Desktop Folder Peek Widget

A lightweight, minimalist Windows desktop application wthat lets you instantly preview and interact with folders on your Windows desktop.

## Features

- **Instant Desktop Folder Peek**:
  - **On Hover**: Hover your mouse cursor over any folder on your desktop — a sleek popup appears with its contents.
  - **On Click**: Prefer clicks? Toggle to single-click mode in Settings.
  - Works with real desktop folders as well as folder shortcuts (`.lnk`).
- **Interactive In-Widget Navigation**:
  - Click any subfolder to browse inside it directly within the widget.
  - Click `[←]` or press `Backspace` to navigate back up.
  - Click `[⊞]` / `[≡]` to toggle between Grid and List view individually for each folder (saved per-folder).
  - Click `[↗]` to open the current folder in Windows File Explorer.
- **Mouse Drag-and-Drop**:
  - **Rearrange Items (Drag Reorder)**: Drag files and folders inside the widget to reorder them manually. Your custom order is automatically saved and remembered for each folder!
  - **Drag to External Apps**: Drag any file or folder out of the widget to the desktop, browser, chat app, or File Explorer.
  - **Drop into Folder**: Drag files from other apps into the widget to move or copy them directly into that folder.
- **Native Windows Context Menu**:
  - Right-click any item inside the popup to access the genuine Windows Explorer context menu (Open, Copy, Cut, Delete, 7-Zip, WinRAR, Properties, etc.).
  - Right-click the popup background for folder options.
- **Customizable Appearance**:
  - **Themes**: System (Auto), Dark Modern, Light Clean, Midnight Blue.
  - **Window Opacity**: Adjustable transparency from 50% to 100% (default: 95%).
  - **Header Height**: Compact header scaling from 50% to 150% (default: 70%).
  - **Corner Rounding**: Adjustable smooth corner rounding from 0 px to 24 px (default: 6 px).
  - **Auto-Size**: Window automatically resizes to fit the exact number of files.
  - **Manual Resize**: Drag any corner (with subtle bottom-right grip) or edge to resize the window manually anytime!
  - **Hide File Extensions**: Clean file display with extensions hidden (enabled by default).
  - **Show Hidden & System Files**: Toggle display of hidden and system files (disabled by default).

## Requirements

- **Operating System**: Windows 10 or Windows 11 (64-bit)
- **Dependencies**: None! Self-contained native Win32 binary (~540 KB).
